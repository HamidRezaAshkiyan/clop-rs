Install in Seconds

Install on macOS or Windows via Homebrew, WinGet, one-line scripts, or Cargo.

brew tap HamidRezaAshkiyan/clop-rs https://github.com/HamidRezaAshkiyan/clop-rs

# Full macOS App + CLI binaries (recommended)
brew install --cask HamidRezaAshkiyan/clop-rs/clop-rs

# Or CLI binaries only (clop-rs & clop-cli)
brew install HamidRezaAshkiyan/clop-rs/clop-rs
winget install HamidRezaAshkiyan.clop-rs
# macOS
curl -fsSL https://github.com/HamidRezaAshkiyan/clop-rs/releases/latest/download/install.sh | bash

# Windows (PowerShell)
irm https://github.com/HamidRezaAshkiyan/clop-rs/releases/latest/download/install.ps1 | iex
git clone https://github.com/HamidRezaAshkiyan/clop-rs.git
cd clop-rs
cargo build --release

Everything Built In

Designed to stay out of your way until you need it — fast, private, and 100% local.

🖼️

MozJPEG + imagequant + oxipng

Progressive + trellis-quantized JPEGs, perceptual 8-bit PNG palette quantization, or strict bit-exact lossless compression with a size guard that never bloats files.

✨

2× HiDPI Floating HUD Toast

Glassmorphic rounded toast with live shimmer progress, thumbnail preview, savings & EXIF pills, hover-to-pause countdown, and one-click [REVERT].

📄

Pure-Rust PDF & FFmpeg Video

Compresses PDF streams & embedded JPEGs natively in Rust (plus optional Ghostscript) and shrinks screen recordings with hardware-accelerated H.264 via FFmpeg.

📥

Auto-Optimize Downloads

Automatically watches ~/Downloads (or any custom folder) for new images, PDFs, and videos with instant one-click rollback.

🔒

EXIF & GPS Privacy Stripping

Strips camera EXIF, GPS coordinates, XMP/IPTC, and PNG text/time metadata chunks before you paste or share files anywhere.

🖱️

Finder & Explorer Context Menu

Right-click any image, PDF, or video and select Optimize with clop-rs — plus a full Web Dashboard (clop-rs ui) and scriptable JSON CLI (clop-cli).
